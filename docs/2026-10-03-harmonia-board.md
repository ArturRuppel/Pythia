# Harmonia board styling

The board shares Harmonia's ground-and-ink header, square paper cards and controls, and an 11 px minimum text size at 100% zoom. The existing board camera still scales the whole stage, so zooming out remains a map view.

Claim-kind colours, edge geometry, paper folds and graph interaction are unchanged. The library, search, PDF dock and programme cards use the same square shape. Header controls retain 44 px touch targets.

The canonical tokens remain in Harmonia. The viewer inlines its vendored copy when building standalone pages.
